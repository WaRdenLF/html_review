Forms

HTML forms allow users to enter and submit information.

<form>

Definition

The form element contains controls used to collect user input.

Attributes

Attribute Role
action Defines where form data is sent.
method Defines the HTTP method used to send data.
target Defines where the response is displayed.

Example - Code

<form action="/submit" method="post">
    ...
</form>

Example - Result

<input>

Definition

The input element creates an interactive field for user input.

Attributes

Attribute Role
type Defines the type of input.
name Defines the name of the field.
placeholder Shows temporary text inside the input.
required Requires the user to enter a value.

Example - Code

<input
    type="text"
    name="username"
    placeholder="Enter your name"
    required>

Example - Result

<label> and <textarea>

Definition

label describes a form control. textarea creates a multi-line text field.

Attributes

Attribute Role
for Connects a label to an input element.
rows Defines the visible number of rows.
cols Defines the visible number of columns.

Example - Code

<label for="message">Message:</label>

<textarea
    id="message"
    rows="5"
    cols="30">
</textarea>
