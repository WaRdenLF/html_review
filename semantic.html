Semantic Elements

Semantic HTML elements describe the meaning and structure of the content.

<header>

Definition

The header element represents introductory content, usually containing a heading or navigation.

Attributes

Attribute Role
class Applies a CSS class.
id Provides a unique identifier.

Example - Code

<header>
    <h1>My Website</h1>
    <p>Welcome!</p>
</header>

Example - Result

My Website

Welcome!

<nav>

Definition

The nav element represents a section containing navigation links.

Attributes

Attribute Role
class Defines a CSS class.
aria-label Provides an accessible name for navigation.

Example - Code

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
</nav>

Example - Result

Home | Text

<main>

Definition

The main element contains the main content of a document.

Attributes

Attribute Role
id Identifies the main section.
class Associates CSS styles.

Example - Code

<main>
    <h1>Main Content</h1>
    <p>This is the main content.</p>
</main>

Example - Result

Main Content

This is the main content.

<section> and <article>

Definition

section represents a thematic section of content. article represents an independent piece of content.

Attributes

Attribute Role
id Identifies the section or article.
class Applies CSS styling.

Example - Code

<section>
    <h2>News</h2>

    <article>
        <h3>HTML News</h3>
        <p>HTML is used to structure websites.</p>
    </article>
</section>

Example - Result

News

HTML News

HTML is used to structure websites.

<footer>

Definition

The footer element represents the footer of a page or section.

Attributes

Attribute Role
class Applies CSS styling.
id Provides a unique identifier.

Example - Code

<footer>
    <p>Copyright 2026</p>
</footer>

Example - Result

Copyright 2026
