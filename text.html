Text Formatting

HTML provides different tags for headings, paragraphs, bold text, emphasized text and other types of text.

<h1> - <h6>

Definition

Heading elements define six levels of headings. h1 is the most important and h6 is the least important.

Attributes

Attribute Role
id Gives the heading a unique identifier.
class Associates the heading with a CSS class.

Example - Code

<h1>Main Heading</h1>
<h2>Subheading</h2>

Example - Result

Main Heading

Subheading

<p>

Definition

The p element defines a paragraph.

Attributes

Attribute Role
id Identifies the paragraph.
class Applies a CSS class.

Example - Code

<p>This is a paragraph.</p>

Example - Result

This is a paragraph.

<strong> and <em>

Definition

strong indicates strong importance. em indicates emphasis.

Attributes

Attribute Role
Global attributes These elements support global HTML attributes.

Example - Code

<strong>Important text</strong>
<em>Emphasized text</em>

Example - Result

Important text

Emphasized text

<br> and <hr>

Definition

br creates a line break. hr represents a thematic break.

Attributes

Attribute Role
Global attributes These elements can use global attributes.

Example - Code

<p>First line<br>Second line</p>
<hr>

Example - Result

First line
Second line
