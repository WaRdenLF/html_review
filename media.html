Multimedia Tags

HTML can display audio, video and external content.

<audio>

Definition

The audio element embeds sound content into a webpage.

Attributes

Attribute Role
controls Displays audio controls.
autoplay Starts playback automatically.
loop Repeats the audio.
muted Starts the audio muted.

Example - Code

<audio controls>
    <source src="images/audio.mp3" type="audio/mpeg">
</audio>

<video>

Definition

The video element embeds video content into a webpage.

Attributes

Attribute Role
controls Displays video controls.
width Defines video width.
height Defines video height.
poster Defines an image shown before playback.

Example - Code

<video controls width="500">
    <source src="images/video.mp4" type="video/mp4">
</video>

Example - Result

<iframe>

Definition

The iframe element embeds another HTML page or external content.

Attributes

Attribute Role
src Defines the URL of the embedded page.
width Defines the width.
height Defines the height.
title Provides an accessible title.

Example - Code

<iframe
    src="https://example.com"
    width="500"
    height="300"
    title="Example">
</iframe>
