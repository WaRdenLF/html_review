Metadata Tags

Metadata provides information about the HTML document. It is mainly placed inside the head element.

<title>

Definition

The title element defines the title displayed in the browser tab.

Attributes

Attribute Role
None The title element has no specific attributes.

Example - Code

<title>My Website</title>

Example - Result

The text "My Website" appears in the browser tab.

<meta>

Definition

The meta element provides metadata about the document.

Attributes

Attribute Role
charset Defines the character encoding.
name Defines the type of metadata.
content Provides the metadata value.
http-equiv Provides HTTP header information.

Example - Code

<meta charset="UTF-8">

<meta
    name="description"
    content="HTML Review Website">

Example - Result

Metadata is processed by the browser and is not normally displayed as page content.

<link>

Definition

The link element defines relationships between the current document and external resources.

Attributes

Attribute Role
rel Defines the relationship with the external resource.
href Specifies the resource URL.
media Specifies the media type or condition.

Example - Code

<link
    rel="stylesheet"
    href="css/style.css">

Example - Result

This website uses style.css through the link element.
