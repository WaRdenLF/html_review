Links and Images

HTML provides the a element for hyperlinks and the img element for displaying images.

<a>

Definition

The a element creates a hyperlink to another page, file, email address or location.

Attributes

Attribute Role
href Specifies the destination.
target Specifies where to open the link.
title Provides additional information.

Example - Code

<a href="https://www.example.com" target="_blank">
Visit Example
</a>

Example - Result

Visit Example

<img>

Definition

The img element embeds an image into a webpage.

Attributes

Attribute Role
src Specifies the image location.
alt Provides alternative text for the image.
width Defines image width.
height Defines image height.

Example - Code

<img src="images/image.jpg"
     alt="Example image">
