Lists

HTML has ordered lists, unordered lists and description lists.

<ul>

Definition

The ul element creates an unordered list.

Attributes

Attribute Role
class Defines a CSS class.
id Defines a unique identifier.

Example - Code

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Example - Result

  • HTML
  • CSS
  • JavaScript

<ol>

Definition

The ol element creates an ordered list.

Attributes

Attribute Role
start Defines the starting number.
reversed Reverses the numbering.
type Defines the numbering style.

Example - Code

<ol>
    <li>Open VS Code</li>
    <li>Create HTML file</li>
    <li>Write code</li>
</ol>

Example - Result

  1. Open VS Code
  2. Create HTML file
  3. Write code

<li>

Definition

The li element defines an item inside an ordered or unordered list.

Attributes

Attribute Role
value Sets the value of an item in an ordered list.

Example - Code

<ol>
    <li>First item</li>
    <li>Second item</li>
</ol>

Example - Result

  1. First item
  2. Second item
