Tables

Tables are used to organize information into rows and columns.

<table>

Definition

The table element creates a table.

Attributes

Attribute Role
class Defines a CSS class.
id Defines a unique identifier.

Example - Code

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Ali</td>
        <td>18</td>
    </tr>
</table>

Example - Result

Name Age
Ali 18
Sarah 19

<tr>, <th> and <td>

Definition

tr creates a table row, th creates a header cell, and td creates a normal data cell.

Attributes

Attribute Role
colspan Makes a cell span multiple columns.
rowspan Makes a cell span multiple rows.
scope Defines the cells a header relates to.

Example - Code

<tr>
    <th>Student</th>
    <th>Grade</th>
</tr>

<tr>
    <td>John</td>
    <td>A</td>
</tr>

Example - Result

Student Grade
John A
