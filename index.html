<!DOCTYPE html>

Definition

The DOCTYPE declaration tells the browser that the document uses HTML5.

Attributes

Attribute Role
None The HTML5 DOCTYPE declaration does not have attributes.

Example - Code

<!DOCTYPE html>

Example - Result

The DOCTYPE declaration is interpreted by the browser.

<html>

Definition

The html element is the root element of an HTML document.

Attributes

Attribute Role
lang Defines the language of the document.
dir Defines text direction.

Example - Code

<html lang="en">
    ...
</html>

Example - Result

This entire page is inside the HTML element.

<head> and <body>

Definition

The head contains metadata and information about the document. The body contains the visible content of the page.

Attributes

Attribute Role
Global attributes Both elements can use global HTML attributes.

Example - Code

<head>
    <title>My Page</title>
</head>

<body>
    <h1>Hello World</h1>
</body>

Example - Result

Hello World

This content is displayed inside the body.
